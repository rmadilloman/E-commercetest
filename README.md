# Basic Front-end Ecommerce

## Description
Simple one page front-end ecommerce layout that features a cart with item storing, built with responsive-design and media queries in mind.

## Technologies
- HTML
- SCSS (SASS)
- JS

## Features
- One page design with sliding cart
- Cart adding
